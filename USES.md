# What collaborators can do with this

## Uses
1. **Reference table.** A page-referenced inventory of what Habib says India had, lacked or half-had in ch. 3.
2. **Extend it.** Code pp. 108, 110 and other chapters (agriculture, crafts, textiles) with the same codebook so chapters can be compared.
3. **Check the coding.** Re-code a sample of rows independently and report agreement. This is the biggest missing step.
4. **Add columns.** Classify Habib's reasons for non-adoption (cost, skill, belief, substitute, none given) to map how he explains absence.
5. **Add a comparison baseline.** Pair each technology with an equivalent entry for Europe, China or the Islamic world, so "missing" has a stated yardstick.
6. **Test dating disputes.** Rows where Habib reports historians disagreeing (cannon, C3-11; rocket, C3-10) can be traced to the original sources.
7. **Teaching.** An example of turning narrative history into a coded dataset, with a codebook and a pipeline.
8. **Writing.** Counts, tables and charts for essays or posts, labelled as a coding of Habib.
